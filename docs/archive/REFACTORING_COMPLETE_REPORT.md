## 🔧 重构方法

### 手动重构

**策略：**
1. 分析文件结构，识别功能内聚的方法组
2. 提取独立工具类，遵循单一职责原则
3. 每次提取后立即测试验证
4. 渐进式重构，从低风险开始

**工具：**
- Edit工具进行精确编辑
- 编译和测试循环验证
- Git提交跟踪每次更改

### Agent并行重构

**策略：**
1. 启动多个agents同时分析不同文件
2. 每个agent独立执行重构、编译、测试
3. 并行执行零风险的重复代码删除
4. 自动验证所有更改

**优势：**
- 并行处理提高效率
- 减少人工错误
- 自动化测试验证
- 处理大规模重构任务
