   - 先达标后优化
   - 降低失败风险

   - 任务隔离
   - 失败可回退
   - 降低风险

   - 同时处理多文件失败率高
   - 应逐文件处理
   - 评估风险再决定

3. **类结构完整性关键**
   - 提取方法块破坏结构
   - 需更谨慎策略
   - 先提取小方法组

4. **时间投入vs成果**
   - 4小时投入
