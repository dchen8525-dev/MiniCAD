## 一、StepPreviewJsonExporter拆分方案

### 优先级和分组

#### 🔴 高优先级（大模块，独立性强）

**1. PreviewPmiTargetBuilder.java** (~4,540行)
- 提取范围：lines 8,027-12,571
- 功能：PMI target building methods
- 包含方法：
  - `buildInstanceIdsByTargetId()`, `toPmiPayload()`
  - 所有`appendPmi*()`方法（~50个）
  - 所有`appendDefinition*()`方法（~30个）
  - 所有`appendProperty*()`方法（~20个）
- 依赖：PreviewPayload, StepEntity, StepCadBuilder
- 原文件保留：delegate方法调用新类

**2. PreviewSemanticTargetCollector.java** (~2,100行)
- 提取范围：lines 12,571-14,672
- 功能：Semantic target collection
- 包含方法：
  - `collectSemanticTargets()` - 主方法
  - 所有`collectTargetsFor*()`方法（~50个）
- 依赖：StepEntity, StepCadBuilder
- 原文件保留：delegate方法

**3. PreviewEdgePayloadBuilder.java** (~1,270行)
- 提取范围：lines 5,263-6,535
- 功能：Edge sampling and payload creation
- 包含方法：
  - `sampleLoop()`, `collectTopologyEdges()`
  - `buildEdgePayload()`, `sampledCurvePayload()`
  - `sampleLooseEdgePoints()`, `curveForLooseEdge()`
- 依赖：EdgePayload, PreviewCurveEvaluator
- 原文件保留：delegate方法

**4. PreviewSurfacePayloadBuilder.java** (~750行)
- 提取范围：lines 2,671-3,420
- 功能：Surface-specific face payload converters
- 包含方法：
  - `toCylindricalFacePayload()`, `toConicalFacePayload()`
  - `toToroidalFacePayload()`, `toBSplineSurfaceFacePayload()`
  - 所有其他surface type converters（~12个）
- 依赖：FacePayload, StepSurface entities
- 原文件保留：delegate方法

#### 🟡 中优先级（中等模块）

**5. PreviewParametricSurfaceProcessor.java** (~600行)
- 提取范围：lines 3,459-4,059
- 功能：Parametric surface processing
- 方法：`toParametricTrimmedFaceResult()`, `buildParametricLoops()`

**6. PreviewPmiPayloadBuilder.java** (~900行)
- 提取范围：lines 7,126-8,027
- 功能：PMI payload creation
- 方法：`buildPmiPayloads()`, 所有`append*Pmi()`方法（~20个）

**7. PreviewTypeNameMapper.java** (~480行)
- 提取范围：lines 4,897-5,182（285行）+ 5,607-5,801（195行）
- 功能：Type name mapping utilities
- 方法：`surfaceTypeName()`, `previewCurveTypeName()`, `geometryTypeName()`

**8. PreviewAssemblyBuilder.java** (~415行)
- 提取范围：lines 2,235-2,649
- 功能：Assembly/representation building
- 方法：`buildAssemblyData()`, `buildRepresentationPayload()`

**9. PreviewTransformationHelper.java** (~385行)
- 提取范围：lines 1,705-2,090
- 功能：Matrix/transformation utilities
- 方法：`matrixForMappedPlacement()`, `transformMappedEdge()`

**10. PreviewPointExtractor.java** (~340行)
- 提取范围：lines 7,689-8,027
- 功能：Point extraction from various entities
- 方法：所有`pointFrom*()`方法（~12个）

#### 🟢 低优先级（小模块，可选）

**11. PreviewEdgeSamplingHelper.java** (~325行)

- 功能：Edge sampling/projection

**12. PreviewCurveEvaluatorFactory.java** (~275行)

## 二、StepEntityResolver拆分方案

### 提取策略
遵循现有`StepTopologyResolver`和`StepProductResolver`模式：
1. 创建专门的resolver类
2. 原文件保留delegate方法
3. 新resolver持有`StepEntityResolver`引用
4. 使用`resolver.definition()`, `resolver.stringValue()`等helper方法

### 提取优先级

#### 🔴 高优先级

**1. StepGeometryResolver.java** (~2,000-3,000行)
- Entity types：~150 curve/surface types
- 方法：所有geometry/curve/surface resolve方法
- 预期：减少主文件~25%
- 位置：`com.minicad.step.semantic.StepGeometryResolver`

**2. StepFeaResolver.java** (~800-1,200行)
- Entity types：~80 FEA types
- 方法：所有FEA相关resolve方法
- 预期：减少主文件~10%

**3. StepAnnotationResolver.java** (~600-900行)
- Entity types：~60 annotation types
- 方法：所有annotation/presentation resolve方法
- 预期：减少主文件~7%

#### 🟡 中优先级

**4. StepToleranceResolver.java** (~500-800行)
- Entity types：~50 GD&T types
- 方法：所有tolerance/datum resolve方法

**5. StepKinematicResolver.java** (~400-600行)
- Entity types：~30 kinematic types
- 方法：所有kinematic相关resolve方法

**6. StepManufacturingResolver.java** (~400-600行)
- Entity types：~40 feature types
- 方法：所有manufacturing feature resolve方法

**7. StepConfigManagementResolver.java** (~600-800行)
- Entity types：~50 config types
- 方法：所有approval/certification/contract resolve方法

#### 🟢 低优先级

**8. StepUnitResolver.java** (~300-400行)
- Entity types：~30 unit types

**9. StepDocumentResolver.java** (~150-200行)
- Entity types：~10 document types

                <goal>report</goal>
            </goals>

            <id>check</id>
            <goals>
